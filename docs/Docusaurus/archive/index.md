# Archived Documentation

## Overview

This directory preserves superseded Mississippi documentation as source material.
It sits outside `docs/Docusaurus/docs/`, so Docusaurus does not publish it or
include it in the technical-documentation sidebar.

Use archived pages as historical reference material, not as the primary navigation path for new documentation work.

## What Is Archived

- [Legacy Documentation Home](legacy-home.md) preserves the previous site landing page.
- [Client State Management](client-state-management/reservoir.md) preserves the earlier Reservoir-focused section.
- [Concepts](concepts/index.md) preserves the earlier concept pages.
- [Reference](reference/index.md) preserves the earlier reference pages.
- `retired-navigation-matrix/` preserves the former subsystem-by-page-type tree
  for review or selective recovery.

## Current Documentation Status

Archived pages are not current guidance and have no supported public routes.
Use the intent-based active manual for all new documentation work.
